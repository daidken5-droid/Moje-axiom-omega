# Matematika a statistika

## Algebra a rovnice
Kvadratická rovnice ax² + bx + c = 0 má kořeny x = (−b ± √(b² − 4ac)) / (2a); diskriminant D = b² − 4ac (D > 0 dva reálné kořeny, D = 0 jeden dvojnásobný, D < 0 komplexní). Vzorce: (a + b)² = a² + 2ab + b², (a − b)² = a² − 2ab + b², a² − b² = (a − b)(a + b). Logaritmy: log(xy) = log x + log y, log(x/y) = log x − log y, log(xⁿ) = n·log x, změna základu log_a x = ln x / ln a.

## Geometrie
Obsah kruhu πr², obvod 2πr. Obsah trojúhelníku ½·z·v nebo Heronův vzorec √(s(s−a)(s−b)(s−c)), kde s je polovina obvodu. Pythagorova věta c² = a² + b². Objem koule 4/3·πr³, povrch 4πr². Objem válce πr²h, kužele ⅓πr²h, jehlanu ⅓·S·h. Sklon v % = převýšení / vodorovná délka × 100; 100 % odpovídá 45°.

## Procenta a poměry
p % z x = x·p/100. Změna v % = (nová − stará)/stará × 100. Procentní bod je rozdíl dvou procent (z 10 % na 12 % = +2 p. b. = +20 %). Pokles o p % a následný růst o p % nevrátí původní hodnotu: 100 → 80 (−20 %) → 96 (+20 %).

## Popisná statistika
Průměr = součet / počet. Medián = prostřední hodnota seřazených dat (odolný vůči extrémům). Rozptyl výběru s² = Σ(xᵢ − x̄)²/(n − 1), směrodatná odchylka s = √s². Variační koeficient = s / x̄. U normálního rozdělení leží cca 68 % hodnot v ±1σ, 95 % v ±1,96σ, 99,7 % v ±3σ.

## Pravděpodobnost a odhady
P(A ∪ B) = P(A) + P(B) − P(A ∩ B). Nezávislé jevy: P(A ∩ B) = P(A)·P(B). Bayesova věta: P(A|B) = P(B|A)·P(A)/P(B). Standardní chyba průměru = s/√n; 95% interval spolehlivosti ≈ x̄ ± 1,96·s/√n. Korelace neznamená příčinnou souvislost. Pro podíl p z n pozorování je směrodatná chyba √(p(1−p)/n).
